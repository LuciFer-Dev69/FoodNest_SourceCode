# FoodNest UAT — Defect Log

Record any deviation from the expected result found while executing the UAT
scenarios (`03-test-cases.md`). Each defect is traced back to its UAT scenario.

## Severity definitions

| Severity | Meaning |
|---|---|
| Critical | Blocks the use case entirely; no workaround. |
| High | Major functionality unusable; significant user impact. |
| Medium | Minor deviation with a workaround. |
| Low | Cosmetic / wording / layout issue. |

## Notes

- UAT cannot be signed off while **Critical** or **High** defects remain open.
- After a fix, re-run the associated UAT scenario in `04-execution-log.md` and
  update the defect status to *Closed* or *Waived* with justification.
